# Ассемблер и интерпретатор учебной виртуальной машины

Практическая работа № 4 по конфигурационному управлению, вариант 15. Язык реализации — Swift.

Ассемблер преобразует текстовую программу в машинный код. Интерпретатор выполняет команды и сохраняет выбранный диапазон памяти в JSON.

## Команды

Каждая команда записывается на отдельной строке. После имени команды указывается целое число. Пустые строки пропускаются.

| Пример | Код `A` | Операнд `B` | Действие |
|---|---:|---|---|
| `LOAD 904` | 0 | Константа | Загружает число в аккумулятор |
| `READ 19` | 2 | Смещение | Читает значение по адресу `аккумулятор + B` в аккумулятор |
| `WRITE 112` | 6 | Адрес | Записывает значение аккумулятора в ячейку `B` |
| `SGN 886` | 1 | Адрес | Читает число из ячейки `B` и записывает его знак по адресу из аккумулятора |

`SGN` записывает `-1` для отрицательного числа, `0` для нуля и `1` для положительного числа.

Поле `A` занимает младшие 3 бита. Поле `B` у `LOAD` содержит 26-битное число со знаком в дополнительном коде, от `-33554432` до `33554431`. Для `READ` операнд занимает 14 бит, для `WRITE` и `SGN` — 21 бит. Эти три команды принимают неотрицательные операнды.

`LOAD` занимает 4 байта, остальные команды — по 3 байта. Младший байт записывается первым.

## Запуск на macOS

Скрипты запускают Swift через `xcrun`. Команды выполняются из корня репозитория.

### Ассемблер

```text
./run.sh <исходник.asm> <результат.bin> [--test]
```

Ассемблер записывает бинарный файл и выводит число собранных команд. Флаг `--test` дополнительно выводит байты каждой команды.

### Интерпретатор

```text
./interpret.sh <программа.bin> <дамп.json> <начальный_адрес> <конечный_адрес>
```

Обе границы диапазона включаются в дамп. Ключи JSON — адреса ячеек, значения — их содержимое. Ячейки без записанных значений читаются как `0`.

## Проверка машинного кода

```sh
./run.sh tests/variant15.asm program.bin --test
```

Ожидаемый вывод:

```text
Ассемблировано команд: 4
0x40, 0x1C, 0x00, 0x00
0x9A, 0x00, 0x00
0x86, 0x03, 0x00
0xB1, 0x1B, 0x00
```

## Проверка копирования массива

`tests/copy.asm` копирует числа `42`, `7` и `99` из ячеек `10–12` в ячейки `20–22`.

```sh
./run.sh tests/copy.asm program.bin &&
./interpret.sh program.bin dump.json 20 22 &&
cat dump.json
```

Ожидаемый дамп: `{"20": 42, "21": 7, "22": 99}`.

## Проверка SGN

`tests/sgn.asm` определяет знак чисел `42`, `0` и `-14` и записывает результаты в ячейки `20–22`.

```sh
./run.sh tests/sgn.asm program.bin &&
./interpret.sh program.bin dump.json 20 22 &&
cat dump.json
```

Ожидаемый дамп: `{"20": 1, "21": 0, "22": -1}`.
