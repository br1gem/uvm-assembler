# Ассемблер учебной виртуальной машины

Практическая работа № 4 по конфигурационному управлению, вариант 15.

На первом этапе ассемблер читает текстовую программу и преобразует каждую
команду в пару полей `A` и `B`. Поле `A` содержит код операции, а поле `B`
содержит её аргумент.

## Синтаксис

Одна команда на строку. После имени команды записывается целое число.
Пустые строки пропускаются.

| Команда | Код A | Аргумент B |
|---|---:|---|
| `LOAD 904` | 0 | Константа для загрузки в аккумулятор |
| `READ 19` | 2 | Смещение относительно адреса в аккумуляторе |
| `WRITE 112` | 6 | Адрес для записи значения аккумулятора |
| `SGN 886` | 1 | Адрес значения, знак которого надо определить |

## Запуск на macOS

```sh
./run.sh <исходник.asm> <результат.bin> [--test]
```

Первый аргумент задаёт путь к исходнику. Второй задаёт путь для записи
машинного кода на этапе 2. Флаг `--test` на этапе 1 выводит поля команд.

## Проверка варианта 15

```sh
./run.sh tests/variant15.asm program.bin --test
```

Ожидаемый вывод:

```text
(A=0, B=904)
(A=2, B=19)
(A=6, B=112)
(A=1, B=886)
```
