# Ассемблер и интерпретатор учебной виртуальной машины

Практическая работа № 4 по конфигурационному управлению, вариант 15. Язык реализации — Swift.

Ассемблер преобразует текстовую программу в машинный код. Интерпретатор читает машинный код, выполняет команды и сохраняет выбранный диапазон памяти в JSON.

## Синтаксис ассемблера

Каждая команда записывается на отдельной строке. После имени команды указывается неотрицательное целое число. Пустые строки пропускаются.

| Пример | Код `A` | Аргумент `B` |
|---|---:|---|
| `LOAD 904` | 0 | Константа для загрузки в аккумулятор |
| `READ 19` | 2 | Смещение относительно адреса в аккумуляторе |
| `WRITE 112` | 6 | Адрес записи значения аккумулятора |
| `SGN 886` | 1 | Адрес значения, знак которого нужно определить |

Поле `A` содержит код операции, поле `B` — её аргумент. Команда `LOAD` занимает 4 байта, остальные — по 3 байта. Младший байт записывается первым.

## Запуск на macOS

Скрипты запускают Swift через `xcrun`. Команды выполняются из корня репозитория.

### Ассемблер

```text
./run.sh <исходник.asm> <результат.bin> [--test]
```

Ассемблер записывает бинарный файл и выводит количество собранных команд. Флаг `--test` дополнительно выводит байты каждой команды.

### Интерпретатор

```text
./interpret.sh <программа.bin> <дамп.json> <начальный_адрес> <конечный_адрес>
```

Границы диапазона включаются в дамп. Ключи JSON — адреса ячеек, значения — их содержимое. Ячейки без записанных значений читаются как `0`.

Интерпретатор выполняет `LOAD`, `READ` и `WRITE`. Выполнение `SGN` относится к этапу 4.

## Проверка машинного кода

```sh
./run.sh tests/variant15.asm program.bin --test
```

Ожидаемый вывод:

```text
Ассемблировано команд: 4
0x40, 0x1C, 0x00, 0x00
0x9A, 0x00, 0x00
0x86, 0x03, 0x00
0xB1, 0x1B, 0x00
```

Размер `program.bin` — 13 байт (`4 + 3 + 3 + 3`). Проверить байты и размер можно командами:

```sh
od -An -tx1 -v program.bin
wc -c < program.bin
```

## Проверка копирования массива

Программа `tests/copy.asm` записывает числа `42`, `7` и `99` в ячейки `10–12`, затем копирует их в ячейки `20–22`.

```sh
./run.sh tests/copy.asm program.bin &&
./interpret.sh program.bin dump.json 20 22 &&
cat dump.json
```

Ожидаемое содержимое `dump.json`:

```json
{
  "20": 42,
  "21": 7,
  "22": 99
}
```
