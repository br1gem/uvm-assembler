# Ассемблер учебной виртуальной машины

Практическая работа № 4 по конфигурационному управлению, вариант 15. Язык реализации — Swift.

Ассемблер читает текстовую программу, разбирает команды на поля `A` и `B`, преобразует их в машинный код и записывает результат в бинарный файл. Поле `A` содержит код операции, поле `B` — её аргумент.

## Синтаксис

Каждая команда записывается на отдельной строке. После имени команды указывается неотрицательное целое число. Пустые строки пропускаются.

| Пример | Код `A` | Аргумент `B` |
|---|---:|---|
| `LOAD 904` | 0 | Константа для загрузки в аккумулятор |
| `READ 19` | 2 | Смещение относительно адреса в аккумуляторе |
| `WRITE 112` | 6 | Адрес записи значения аккумулятора |
| `SGN 886` | 1 | Адрес значения, знак которого нужно определить |

## Запуск на macOS

Скрипт `run.sh` запускает Swift через `xcrun`. Формат запуска:

```text
./run.sh <исходник.asm> <результат.bin> [--test]
```

Первый аргумент задаёт путь к исходной программе, второй — путь к бинарному файлу. Ассемблер выводит количество собранных команд. Флаг `--test` дополнительно выводит байты каждой команды в шестнадцатеричном виде.

## Проверка варианта 15

Тестовый файл `tests/variant15.asm` содержит примеры всех четырёх команд из методички. Запусти из корня репозитория:

```sh
./run.sh tests/variant15.asm program.bin --test
```

Ожидаемый вывод:

```text
Ассемблировано команд: 4
0x40, 0x1C, 0x00, 0x00
0x9A, 0x00, 0x00
0x86, 0x03, 0x00
0xB1, 0x1B, 0x00
```

Проверить содержимое и размер бинарного файла можно командами:

```sh
od -An -tx1 -v program.bin
wc -c < program.bin
```

В файле должно быть 13 байт: 4 байта для `LOAD` и по 3 байта для `READ`, `WRITE` и `SGN`.

```text
40 1c 00 00 9a 00 00 86 03 00 b1 1b 00
```
